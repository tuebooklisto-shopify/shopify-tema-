# AVVORA

**Editorial premium de ebooks prácticos.** Lema: "Diseñado para aprender. Creado para avanzar."

**Esencia:** Calidad antes que cantidad. Enseña habilidades (no recetas). Voz de experto, nunca vendedor. Minimalismo editorial, paleta neutra, fotos hiperrealistas.

**Target:** Personas que valoran aprender, ahorrar dinero y hacer las cosas por sí mismas.

## Productos

**Estructura:** 1 ebook + 3 bonos  
**Formato:** Portada → Intro → Fundamentos → Capítulos → Consejos → Errores → FAQ → Cierre

**Actual: Suavizante de Ropa (MVP)**  
Estado: En construcción | Objetivo: Validar mercado  
Contenido: Química, herramientas, materias primas, proceso paso a paso, errores, conservación  
Propósito: Enseñar el proceso completo, no solo receta.

**Roadmap:** Suavizante (ahora) → Meta Ads → v1.1 ampliada → Detergente, limpiador multiuso, jabón.

## Principios

Calidad > velocidad | Valor real, nunca engaño | Cada decisión fortalece la marca.
